1. A Different Kind of Zero

Mirror Calculus builds upon Traction Theory, an algebra with a non-absorbing zero. Similar to a ring and field, a traction is a general-purpose algebraic object with restrictions around zero notably absent from the definitions.

The classic assumption 0*x = 0 does not hold.

0*x != 0

Instead, we conserve information, only erasing information under universal invariance, the operational identities, and keeping everything else as residual terms.

x-x=null

But the residuals are not merely formal bookkeeping terms. We find by analyzing the Chebyshev Polynomials, real useful structure emerges from arithmetic of the totalized zero.

2. Traction Jet from Zero

Given:

f(x) = x^{2}+3*x-4

We offset x by zero and scale the function by zero.

0*f(x+0) = 0*((x+0)^{2}+3*(x+0)-4)
0*f(x+0) = 0*((x^2+2*0*x+0^2)+(3*x+3*0)-4)
0*f(x+0) = 0*(x^2+3*x-4+2*0*x+3*0+0^2)
0*f(x+0) = (0*x^2+3*0*x-4*0)+(2*0^2*x+3*0^2)+0^3

The resulting ordered expansion is called the Traction Jet. It plays the role of a Taylor jet, with successive powers of the traction parameter encoding successive differential orders.

In Traction Theory, 0*w=1 Multiplying by ω cancels the first order of 0.

w*(0*f(x+0)) = f(x+0)

This leaves behind non-zero terms.

f(x+0) = x^2+3*x-4+(2*0*x+3*0)+0^2

And we use the projection operator to truncate zero-terms. This recovers the original function exactly.

For the sake of simplicity, the projection operator ℚ discards every traction order, retaining only the zeroth-order component.

ℚ(f(x+0)) = x^2+3*x-4

Now we recover the first derivative by again multiplying by ω

w*f(x+0) = w*x^2+w*3*x-w*4+(2*x+3)+0

Because ω lowers traction order by one, the coefficient of the first-order traction term becomes the zeroth-order component. After projection, this coefficient is precisely the derivative.

ℚ(w*f(x+0)) = 2*x+3

3. Additive versus Multiplicative Reflections

Borrowing from the last example, we have a function with a zero offset.

f(x+0) = x^2+3*x-4+2*0*x+3*0+0^2

Then we subtract the original function, and what remains is the discrete forward differential.

f(x+0)-f(x) = x^2+3*x-4+2*0*x+3*0+0^2 - (x^{2}+3*x-4)

What's left after erasure is the signature of a zero-offset difference.

f(x+0)-f(x) = 2*0*x+3*0+0^2
3.1 Multiplicative Differential
f(x+0)/f(x) = (x^2+3*x-4+2*0*x+3*0+0^2) / (x^{2}+3*x-4)
f(x+0)/f(x) = {x^2+3*x-4}/{x^2+3*x-4} + {2*0*x+3*0+0^2} / {x^{2}+3*x-4}
f(x+0)/f(x) = 1 + 0*{{2*x+3}/{x^2+3*x-4}}

Prior to projection, the ratio differs from unity only by first-order traction terms. Now see what happens when we divide out the zero:

f(x+0)/{0*f(x)} = 1/0 + {0/0}*{{2*x+3}/{x^2+3*x-4}}

Recall from Traction Theory: 0/0=1

f(x+0)/{0*f(x)} = 1/0 + {2*x+3}/{x^2+3*x-4}

And the 1/0 term can be written as ω.

f(x+0)/{0*f(x)} = w + {2*x+3}/{x^2+3*x-4}

Dividing by the traction-scaled function separates the expression into a pure traction component and a normalized differential component.

The traction algebra is naturally interpreted using the Riemann sphere.
