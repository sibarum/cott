Every building block the intro uses, in one place

The lead paragraph sets up the chapter in a few sentences. Copy this file to start a new chapter, then delete whatever you don't need. Inline math is written either as plain Unicode in a math-inline span, like a + b = c, or as ASCII that the engine formats for you, like x^2 + y_{1} = 0^(w/2).

Auto-formatted expressions

Write the ASCII source inside a dynamicexpr span and the engine replaces it on load. Display equations go in a .eqn wrapper:

0^w = -1
i = 0^(w/2)
a (+) b := 1/(1/a + 1/b) = a*b/(a+b)
S_{p}(x, y) = (x^p + y^p)^(1/p)
x (+/-) y = z (-/+) y
a (><) b = -(b (><) a)
sqrt(x^2 + y^2) = r

Operators: (+) ⊕, (+/-) ±, (-/+) ∓, (><) ×, (*) explicit dot. w becomes ω, * becomes a dot (or juxtaposition), / stacks into a fraction, and ^ / _ raise and lower. Use braces for multi-character scripts: S_{p}, 0^{2*w}.

Hand-set math

For an aligned block that the engine shouldn't parse, use .math with Unicode:

0⁰ = 1 0¹ = 0 0⁻¹ = ω 0⁻ⁿ = ωⁿ ω⁰ = 1 ω¹ = ω ω⁻¹ = 0 ω⁻ⁿ = 0ⁿ

Confidence badges

Proven a theorem or machine-checked result. Plausible a load-bearing bet. Wild speculation. A badge can carry a hover citation: Proven

Callouts, notes, and footnotes

A callout. Use .section-alt for an aside that deserves a box, with math allowed inside.

Footnotes use a superscript reference1 and a list at the end of the chapter. Links to other chapters are ordinary relative links, like the contents.
