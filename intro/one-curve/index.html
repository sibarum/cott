One Curve, Two Rates

Base −1 is base 0, read ω times faster

Status: SUPERSEDED by The Anchor Was a Shadow. The law it proposes was replaced the same day; the check table and the x=0 analysis are retained as working history. Draft, unverified, not canon. Third in the thread that runs The Reversible One → The Slot-Closure Formulation. Linked from nowhere on purpose. Unlike its two predecessors this note makes one claim and spends the rest of its length checking it, so the open questions at the end are narrow rather than structural. Read it as a lab notebook.

The slot-closure note tried to link all eight exponential schemas into a single closed chain and produced a chain that contradicts itself at the unit constants. The repair turned out not to be a sign but a re-routing, and the re-routed link does something the original never did: it earns back two identities that Chapter 7 currently has to posit separately. The imaginary unit and the closing of the circle are the same law, sampled at two points.

The law

Written as a schema identity over a free parameter x:

(−1)^x = 0^(xω)

In words: the base-(−1) curve and the base-0 curve are the same curve, traversed at rates differing by a factor of ω. Base −1 is not a new object to be linked into the chain alongside base 0; it is base 0 with the exponent rescaled.

It sits in a set of four, of which it is the fourth:

A: x^1 = x/1 ⟶ x^(−1) = 1/x B: 1^x = x^0 ≈ 1 C: 0^x = ω^(−x) ⟶ ω^x = 0^(−x) D: (−1)^x = 0^(xω)

Note the ≈ in B. 1^x = x^0 is the reversible identity — the one The Reversible One arrived at by chasing the 0^(0ω) contradiction. The further step to 1 is a projection, true downstairs among the classical numbers and lossy on the way, so it is written with the sign that says so. Reading that step as an equality is what made base-1 look like a constant, and a constant is what the failed chain tried to link a sign-alternating schema to.

What went wrong before, in one line. The previous chain routed base-(−1) through base-1. But base-1 is constant on the integer exponents and base-(−1) alternates, so any pointwise identity between them fails wherever the alternating one is not sitting at 1 — at x = 1 it reads 1 = −1 outright. That is not a bad choice of sign; no choice of sign repairs it. D routes through base-0 instead, which also alternates, and the mismatch disappears.

The x = −1 row uses only that reciprocals behave, which A supplies. Every row but the last two is either verified or a known canon value.

The table is downstairs; D is upstairs. The four-by-four table of unit constants is a projection — every one of its cells is reached by collapsing B across the ≈, since the whole x^0 column is the base-1 curve. Checking a schema identity against it therefore proves nothing on its own, and can manufacture both false agreement and false contradiction. The x = 0 row below is where that actually bites. Everywhere else the sample point passes through the exponent untouched — 1·ω = ω, (−1)·ω = −ω — and the check is honest.

What it earns back

The two bolded rows are the reason this note exists. Chapter 7 currently introduces them as two separate consequences of the normalization 0^ω = −1: the imaginary unit appears because 0^(ω/2) squares to −1, and the circle closes because going twice around returns home. Two facts, each posited, each checked by hand.

i = 0^(ω/2) is D at x = ½ 0^(2ω) = 1 is D at x = 2

Under D they are not two facts. They are one law read at two points, and the points are the ordinary ones: (−1)^½ = i and (−1)² = 1 are what anybody would write for base −1. The content of D is that base 0 is base −1, slowed by ω — so everything already known about powers of −1 transfers to powers of 0 for free, and the half-power landing on i stops being a happy accident of the chosen normalization.

This is the first thing in the thread that pays the canon back rather than qualifying it. Both predecessors took things away — x⁰ = 1 in the first, the four-element bijection argument in the second. D returns something: two posits become one law.

The x = 0 row, which is not a formality

At x = 0 the law reads:

(−1)⁰ = 0^(0·ω)

and the right-hand side is exactly the quantity The Reversible One opens on — the one that classically detonates the whole construction. It is also the only sample point where the exponent is not inert. Everywhere else xω simply carries x along; here it lands on the definitional identity 0·ω = 1, and the shortest evaluation is a single substitution:

0^(0·ω) = 0¹ = 0

No power rule, no splitting of the exponent, nothing contestable. 0·ω = 1 is fixed by definition in The Invertible Zero, and = in this book means a rewrite that carries the same information both ways — so substituting it into an exponent is not merely permitted, it is the obvious reading, and any longer route that reaches a different answer is the one under suspicion.

So D at x = 0 does not agree with the table. It contradicts it, and the contradiction is the interesting part:

D at x = 0: (−1)^0 = 0^(0·ω) = 0 B at x = −1: 1^(−1) = (−1)^0 ───────────────────────────────────── 1^(−1) = 0

Which is precisely the constraint The Reversible One derived — 1^(0^ω) = 0, with 0^ω = −1 — reached here from an entirely different direction, and without the step that note had to argue for. Two independent routes to the same constraint is the strongest evidence in the thread.

So the disputed cell is 1^(−1), and the table has it wrong. B reads 1^x = x^0 ≈ 1, with the collapse marked lossy — which means the entire x^0 column is the base-1 curve, equal to 1 only downstairs. The table records 1^(−1) = 1; that is the projection, not the value. Upstairs, D and B together say 1^(−1) = 0. This does not settle The Reversible One's first open item — the tower 1^s = e^(2πis) still says 1^(−1) = 1, and now has two derivations against it rather than one. The clash is unchanged in substance and sharper in outline: the tower and the constraint disagree about base 1 at exponent −1, and something has to give.

What this does not cover

Four laws, eight slots — but the count does not come out. A covers x^1 and x^(−1); B covers 1^x and x^0; C covers 0^x and ω^x; D covers (−1)^x alone. Seven. x^ω has no law.

D does put ω in an exponent, but on base 0 — that is the 0^x schema at a rescaled argument, not the x^ω schema, which wants ω fixed upstairs and the base free. The previous chain's third link was the only one that touched it, and the repair discarded that link.

The gap and the last row of the check table are the same gap. Reducing 0^(ω²) the obvious way,

0^(ω²) = (0^ω)^ω = (−1)^ω

lands precisely on the missing schema.2 So 0^(ω²) is not an independent puzzle to be solved before the eighth link — it is the eighth link, wearing a different coat.

Why guessing a value for it would be a mistake. Read by grade, ω² sits at grade −2, but 0^ω = −1 sits at grade 0 — the ω-exponent rotates phase rather than shifting grade, while integer exponents shift grade and do not rotate. The exponent slot of base 0 is being read in two registers at once, and ω² asks the two to compose. The prior question is therefore structural, not numerical: is the exponent register of base 0 closed under multiplication? If it is, the tower 0 → −1 → ? continues and the carrier grows past four elements. If it is not, ω² does not denote, and the puncture conjectured at the end of the slot-closure note — integer powers shrink, 0^ω wraps, and the two live in sectors that cannot see each other — is real. Either answer is a result. A value chosen to make the table close is not.

This is load-bearing further back than it looks. If the carrier grows past four, the four-element bijection that fixed 0^ω = −1 in the first place no longer applies, and the normalization the whole circle rests on is back open — a debt the slot-closure note already recorded and nobody has paid.

Open

  1. The eighth link. x^ω, equivalently (−1)^ω, equivalently 0^(ω²). The natural place to look is not the chain but Where the Choices Show, which already reads 0^ω as a phase generator sampled at ω and has a period knob; x^ω is that generator at arbitrary base.
  2. The register question. Closed under multiplication, or punctured. Everything in item 1 is downstream of it, and it is answerable without settling anything else in the thread.
  3. The status of A. x^1 = x/1 discharges a slot into division — outside the exponential language, which is the one move the slot-closure discipline forbids. Either it is a definition and wants :=, or the bar is being deliberately relaxed at exponents ±1 on the grounds that this is exactly where exponentiation meets the multiplicative group. The second is defensible; it is not yet stated.
  4. Scope of the check. D is verified at x ∈ {−1, ½, 1, 2}, constrains at x = 0, and is open at x = ω. Nothing has tested it at a general rational, and the half-integer row is the only evidence that it behaves off the integer lattice at all.
  5. 1^(−1): tower or constraint. Inherited from the first note and now sharper — D + B give 0, the tower gives 1. Nothing here breaks the tie, and the tie is load-bearing for base 1 being the fixed curve of the branch involution.
  6. Re-audit the four-by-four table. Every cell is a downstairs projection and should carry ≈, not =. Until that is done, no schema identity can be honestly checked against it — the x = 0 row above was found only because the collapse happened to be visible there.
  7. Whether D makes base (−1) an anchor at all. If base −1 is base 0 rescaled, it may not deserve its own slot in the closure problem — which would make the eight-slot framing itself slightly wrong, and the target count seven.
  1. Provenance: D and the four-law set are the framework's, arrived at by reworking the failed chain after the 1 = −1 collision was found. The verification table, the x = 0 analysis, the slot count, and the register framing are reconstruction and should be re-derived before any of this moves toward canon. ↩
  2. This reduction is offered as a pointer, not a derivation. It uses (a^b)^c = a^(bc), which is precisely the rule The Reversible One identifies as false by a winding number over the complex numbers — the branch-cut failure of log(a^c) = c·log(a). Any constraint on ω² extracted this way inherits that doubt, including the tempting ω² ≡ ω (mod 2ω) that follows if one also assumes (−1)^ω = −1. ↩
